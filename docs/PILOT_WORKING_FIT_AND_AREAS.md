# Work from a saved fit and edit multiple area instructions

The selected earlier starting fit now has its own working card, above the latest
attempt saved for comparison. **Work from this starting fit** opens the selected
original/reconstruction pair and permits area edits. **Use this fit and save marked
areas** records the working source and annotations in the current workspace. It
does not change the historical fit or its anatomical review, approve a result,
prepare a trial or start an optimizer. Settled matching previews suffice; full
detail remains optional for inspection.

The next preparation action explicitly plans from the selected saved geometry,
measurements and field. The previous failed attempt remains in search history,
but cannot silently replace that numerical seed. Only compatible learned, nested
or complete residual-field initialization is allowed on this route. A basis
change requiring fresh initialization is explained and blocked. Preparing a trial
still requires the separate **Run prepared test** action before computation.

**Show where this fit needs improvement** now opens one editor for up to eight
independent points. Repeated surface clicks add A, B, C and so on. Select a point
in the list to change its own instruction, brush/box extent, or position. Every
area stays visible: orange for the selected patch, yellow for other improvements,
blue for retained patches. **Save all marked areas** commits the complete set;
Cancel discards the session. Existing source-bound patches retain their exact
coordinates and sizes unless edited. Removing all existing points is an explicit
clear rather than an empty payload that might accidentally erase prior marks.

Each improvement has its own symptom. **Retain this area in place** uses the
existing fixed-position protection; **Retain this part's shape; allow movement**
uses the existing shape-preservation role. These instructions retain their
separate roles during validation, feedback and successor preparation. Retention
is relative to the selected fitted field, not anatomical approval or a guarantee
of zero motion. The regional objective's existing tolerances still apply.

Verification covers mixed instructions, batch save/reopen/cancel, individual
move/remove/resize, empty-region gates, legacy geometry preservation, settled
preview gates and the actual selected-field staging/dispatch path. Synthetic
controller receipts and public geometry do not establish native fit quality,
convergence or speed. A read-only replay of saved owner metadata also verifies
the selected reference without preparing or running an owner trial. Numerical
equations, accuracy settings and iteration limits are unchanged. Installed
delivery is tracked separately.
