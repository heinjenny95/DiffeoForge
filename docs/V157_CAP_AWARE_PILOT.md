# v157 — finish a bounded optimization before changing the model

Owner first use of v156 still missed relevant local shape features after several
detail adjustments. The software delivery checks had not established anatomical
improvement. v157 changes guided next-step selection; development starts no new
scientific fits and does not approve the existing results.

An inspected, technically valid single-form result with an explicit native
maximum-iteration stop is offered **Optimize longer with the same settings**
before another automatic parameter adjustment. The new separately prepared study
retains its exact fitting parameters and compatible saved momenta/control points,
and doubles that result's per-run iteration allowance. It starts new optimizer
history; it is not a checkpoint continuation or a claim of an identical numerical
trajectory. Preparation still requires a separate Run and fresh visual review.
Subsequent guided batches retain at least this allowance rather than silently
returning to the screening cap. Numerical convergence and visual suitability are
separate decisions.

Worse/same/uncertain feedback retains the earlier reference. An unchanged saved
field cannot repeatedly receive the same longer-optimization test; a newly
improved field may receive more time if it again reaches its cap. Explicit
alternative adjustments remain available, including for a distortion complaint.
Unknown stops, failures, converged fits and multi-form sources do not qualify for
this saved single-field route.

Two completed detail attempts without suitability, or a non-improving detail
attempt, move the automatic suggestion to a different explanation: stronger
surface agreement, then a small local-movement test with an explicitly fresh
initialization. History is scoped to the same form and method. Once these
hypotheses have been tried, the UI explains why input/template inspection is the
next step rather than endlessly reducing the same width. Specific adjustments
remain selectable. Marked regions measure local agreement; they do not create
local attachment weights or uniquely identify the cause of a mismatch.

Regression checks cover explicit cap evidence, exact parameter/field retention,
bounded allowance, reopening, duplicate prevention, earlier-reference feedback,
cross-form history isolation and the actual asynchronous prepare button without
native dispatch. Source, exact frozen and installed checks, backup/idle guards
and delivery synchronization are separate gates. Prospective anatomical benefit
and owner acceptance remain open; no parameter choice is guaranteed to recover a
particular local feature.
