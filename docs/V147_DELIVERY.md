# v147 internal delivery — automatic pilot method comparison

The tested Windows runtime `6938897391e5dfc9b7347f1cf7ba3acd527fa77b`
(`dev147`) is installed. Documentation commits made after the build are a
separate source HEAD. The previous v146 installation is preserved in a verified
recoverable backup. This is an internal engineering delivery, not a public release.

New guided desktop projects default to **Automatic — compare both methods
(recommended)**. The pilot compares Current and Varifold using three matched
settings each, common original-surface distance and regional diagnostics, and a
cautious recommendation rule. A clear numerical advantage does not grant
anatomical approval. Existing projects restore their saved method; selecting
Automatic requires explicit preparation and creates a separate pilot directory.
See the [protocol and limits](V147_AUTOMATIC_ATTACHMENT.md).
