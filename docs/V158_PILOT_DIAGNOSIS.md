# v158 — recover an exhausted pilot with evidence and a bounded basis test

First use of v157 exposed a recovery dead end: unsuccessful surface-scale,
surface-weight and movement-scale hypotheses ended with generic input advice
and a stale disabled preparation label. Completion of those trials did not
establish that the parameter space had been exhausted.

The guided route now offers one **Test additional control points** hypothesis
on the affected form before falling back to input inspection. This requires an
inspected, technically valid singleton source. It adds 50% more controls, rounded
up, within a 2,000-point preparation bound. The method, original template and
target, deformation kernel, attachment scale and surface weight remain unchanged.
Every original control coordinate and momentum is retained in order; extra
controls have zero initial momenta. This embeds the saved initial field in the
larger basis rather than projecting weights onto a different kernel or starting
from zero. New optimizer history, an explicit Run and fresh visual review remain
required. No identical floating-point trajectory or anatomical benefit is claimed.

The chosen common control basis is carried into subsequent single-form coverage
and joint confirmation. Other forms start with their own unfitted field; a field
learned for one target is never copied to another. Later compatible refinement
can retain the expanded saved field. Failed hypotheses keep the earlier selected
starting fit and never create anatomical approval.

**Saved attempts and input checks** shows the actual adjustment, recorded visual
feedback, native stop signal, number of controls and marked-area regression
warning, with direct saved-fit inspection. The other-method action opens its
existing inspected result instead of being a disabled instruction. If no new
automatic hypothesis is available, the stale preparation action disappears and
the diagnostic panel opens. A separate read-only viewer compares the original
prealigned target and template, explicitly labeled as an input check. It cannot
approve a reconstruction, change landmarks or run fitting.

The marked areas remain measurements, not local attachment weights or a unique
diagnosis. This is a general surface-data workflow, without anatomy-specific
feature counting. Numerical convergence and visually sufficient shape agreement
remain separate. A new hypothesis is not evidence of successful fitting.

Regression checks cover the exhausted sequence, exact nested coordinate/momentum
embedding and initial-velocity equality, tamper rejection, original evidence
preservation, unchanged coverage/joint basis, real asynchronous buttons, readable
diagnostics and the original-input viewer. Synthetic execution controllers replace
all fits during engineering verification. Installed-runtime checks and owner
first-use acceptance remain distinct from these source checks.
