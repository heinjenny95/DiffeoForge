# v128 — optional early atlas review

New preserved-pilot atlas handoffs run through the configured native optimizer
stop by default. A visible, unchecked option enables the deliberate checkpoint
after ten joint iterations. Individual initialization, pilot momentum identity,
the common atlas model and native likelihood/gradient/line-search/tolerance
equations are unchanged. Final full-cohort anatomical QC remains separate.

For an existing completed pilot, use **Prepare atlas with saved pilot fits** and
the checkbox beside that action to create the linked launch configuration. This
does not refit the pilot or rewrite its historical selected configuration.

Changing the launch choice creates a linked configuration when necessary; it
does not rewrite the completed pilot or transfer its approvals to a new result.
Existing protected contracts without the new field retain their historical
meaning. Invalid non-boolean choices are rejected.

An existing early checkpoint offers **Review first**, **Continue without early
check**, and cancellation. Explicit continuation records a separate choice bound
to the verified checkpoint and early comparison receipt. It does not write an
anatomical approval, clear a recorded rejection, or rewrite old outputs. Canonical
immutable successors retain this evidence and all initialized specimen rows;
the native optimizer loads the saved parameters and skips repeated initialization.
Native resume still reinitializes its gradient/step history, so this is not an
uninterrupted numerical trajectory claim.

Stopped executions replace the stale live-activity label with a stopped-state
message. The configured iteration cap and final-export policy remain unchanged;
an intermediate checkpoint or a cap is not native tolerance convergence.

Scoped regressions cover default/opt-in configuration, immutable source bytes,
choice bindings and stale evidence, preservation of recorded rejection, canonical
successor inheritance, native-adapter composition without early mesh exports,
and the desktop continue/review/cancel dispatch. Build, installation and any
owner-authorized scientific continuation are documented separately from these
software checks. No installer distribution or public release is implied.
