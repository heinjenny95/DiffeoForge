# Pilot review follow-up

dev218 addresses the collected review and continuation issues without changing
existing scientific runs, iteration caps or numerical tolerances.

## Choosing between saved fits

Both selection buttons name the actual method, saved test and control-point
count. An unranked comparison or a local trade-off keeps the two choices at the
same visual priority. A lower whole-surface distance does not establish a winner
when a measured local area regresses. The comparison uses separate action rows
so the method labels remain accessible in small windows. Selection still
requires matching, settled overlays and does not approve a fit.

## Marking extra reconstructed material

The correction editor has an explicit surface to pick, including the
reconstruction while viewing an overlay. Red corrections can identify fitted
material inside an opening where the original has no surface. The mark binds
the inspected reconstruction hash, ordered topology and selected material faces.
New marks must match the inspected output. Subsequent measurements can follow
the same material through a deformation with unchanged connectivity.

An empty original brush leaves the original-to-fit measurement unknown. The
reverse measurement still reports the selected fitted material's distance to
the complete original. Preparing a local surface test records any nearby
connected original support separately. That support is a geometric fitting
hypothesis, not an anatomical correspondence. A genuine extra connection needs
template/input review: a diffeomorphic deformation cannot remove its topology.
Green original-surface protection and legacy original marks keep their meaning.

The editor separates its canvas and controls with a resizable layout, switches
to a vertical arrangement in narrow windows and wraps control descriptions.

## Continuing an improving capped fit

For an inspected unsuitable individual or protected local fit, the pilot can
present its existing eligible continuation directly in the next-step area. It
requires a finite improving tail of logged native objectives at the recorded
final iteration, the exact saved source field and an explicit existing allowance.
Changed marks, measured regression or failed preservation block the
recommendation. The explanation distinguishes objective progress from observed
surface improvement. Preparation and Run remain separate explicit actions.

The new presentation does not change numerical-extension eligibility. A suitable
fit keeps its next-form or atlas-setup route; optional further refinement still
requires the existing explicit review workflow. No additional iterations are
automatically started and no existing cap is raised.

## Performance qualification boundary

The reduced viewer is independent of the scientific surface geometry. A local
test can still integrate and compare the full surface as well as its local and
protected objects. Target self-varifold caching already exists in the native
runtime; it is not a new acceleration in this version.

The isolated performance tools compare a candidate target-preparation cache and
declare a reduced/full scientific comparison with bound inputs, initial field
and unchanged numerical settings. These tools do not enable an approximate
production fit. Microbenchmark gains and tiny CPU checks cannot establish a
whole-fit GPU speedup or preservation of fine anatomical features. Scientific
multiresolution remains gated on measured complete runtime, full-resolution
quality checks and matched anatomical review.

A bounded native CPU comparison used a controlled narrow surface change and
the same total optimizer allowance for full-only and coarse-then-full fitting.
The candidate shortened the tiny experiment but increased local signal error
and symmetric surface tails. It failed the quality gate and is not enabled.
The isolated target-preparation cache also failed its strict numerical equality
gate. These are negative qualification results, not a faster production solver.
See the [native CPU measurements and remaining qualification](REFERENCE_FIT_PERFORMANCE.md).

## Verification and limits

Regression cases exercise both method-labelled choices, local trade-offs,
continuation eligibility and dispatch, reconstruction-only measurements,
save/reopen/preparation, stale output and topology rejection, preserved inputs
and small-window layout. The local measurement test uses the actual native
distance worker. Source tests, frozen Windows checks, installation state and
independent anatomical qualification are separate evidence.
