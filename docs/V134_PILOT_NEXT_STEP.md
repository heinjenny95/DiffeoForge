# v134 — a visible next step after pilot decisions

Stages 2 and 3 keep the previously approved reconstruction in a fixed footer,
outside the folded tools and candidate scroll area. After all new options are
explicitly rejected, this becomes the highlighted next action with the retained
stage and destination stated. It prepares the next stage without fitting again
or inventing a new anatomical approval. Provisional convergence warnings remain
visible. Incomplete, unreviewed and technically failed options do not count as
anatomical rejection. Technical-screen retry is also visible outside the tools.

Stage 4 has one contextual primary action: choose/review a saved fit, check its
time resolution, recalculate with more time steps after an integration mismatch,
inspect verification problems, or finish. A provisional finish retains its
iteration-limit warning. A recalculation uses the explicitly selected saved fit,
not a different later candidate. Every new fit still needs review and numerical
checks. Pending legacy calculations retain their original declaration.

Repeated specimen-level check messages are deduplicated inside folded details;
the visible status explains the current blocker and next step briefly. Optional
optimizer continuation is folded and optional tools use clearer labels. Native
equations, iteration budgets, thresholds and completion/approval gates are
unchanged. No calculation, selection or approval occurs merely by displaying a
stage or changing the selected saved fit.

Regression and actual source/frozen layout verification are recorded separately
from installation and independent first use. Installation requires a saved,
normally closed application and idle scientific workers; existing owner work
must never be interrupted. This version includes the previous v133 comparison
identity guards. No installer upload was requested.
