# Keep progress while checking one shared model

Individual suitable fits and common-model coverage have different scopes. A
protected local correction, especially a composed residual field, cannot silently
become a standard atlas field. Previously, rejecting a short common-model check
could return the pilot to individual repair and then prepare the same common
check from a fresh field. This repeated work without resolving shared coverage.

The pilot now keeps the chosen common protocol until the researcher explicitly
revises it. Coverage counts use that protocol even while another individual
configuration is being inspected. Earlier fit files and decisions remain saved.
Approving a different ordinary configuration offers an explicit model revision,
including its resulting coverage count. It does not silently reset the protocol.

For each missing common-model form, the next action searches the verified cohort
history for matching ordinary fields. An existing unreviewed result opens for
review without another computation. A reviewed, cap-limited matching field can
continue with the existing 120-iteration allowance, retaining its complete
control/momentum field, template, method, numerical grid, precision, tolerance
and settings. This is a warm field continuation with fresh optimizer history;
cumulative effort and the restarted native counter are reported separately.
There is no claim of an uninterrupted optimizer trajectory.

Further continuations require feedback. An explicit non-improvement or a native
stop other than the cap blocks unchanged repetition and points to model revision.
Optional individual repairs stay separate from common-model checks. A different
animal never receives another animal's momenta or approval. Only explicitly
approved, compatible ordinary fields can initialize the joint check. That joint
result still requires its own anatomical review and the existing numerical gates.

Qualification covers retained local approval, warm common continuation, existing
result reuse, cumulative accounting, no-improvement recovery, deliberate model
revision and joint preparation, plus Qt dispatch without fitting. Real engineering
successors are isolated from owner studies; native quality observations do not
create anatomical approval. No iteration ceiling, accuracy, equations, historical
contract or prepared/running trial is changed. New attempts remain free of timed
review pauses. Exact-package and installed provenance are recorded separately.
