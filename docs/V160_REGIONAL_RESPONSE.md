# Persistent marked areas and evidence-guided follow-up

Marking an original surface identifies where the researcher wants a better fit.
It does not add a local attachment term or establish anatomical correspondence.
The pilot now compares saved reconstructions on the same current marked patches
before proposing the next adjustment.

Empty feedback or a separate suitability review no longer deletes a patch. Clear
has an explicit, source-bound record, carried through feedback, reopening and
successor preparation. An old empty payload is ambiguous: the viewer can recover
an earlier same-source patch without rewriting its history. A researcher can
explicitly Clear recovered marks. Different specimens and changed input identities
cannot exchange patches.

Background preparation checks each saved reconstruction's bindings and measures
its response on identical original patches. Mean and tail distances from the
marked original surface, reverse distances and whole-shape agreement remain
separate. Reducing only reverse distance is insufficient to declare a marked
original patch improved. Sampling uncertainty and mixed changes are retained.

Suggestions use measured improvement, stagnation and regression alongside human
feedback. A human Worse veto prevents promotion; global improvement cannot hide
a worse marked patch. Untried explanations outrank repeated regional failures.
Useful directions may receive another distinct contrast. Repeated control-density
tests retain only compatible, inspected fields without measured regional or global
regression. Historical results and the human-preferred comparison remain available.
Optional alternatives are still possible; several stalled families expose input
and template checks without a cumulative trial cap or once-per-family dead end.

Measurement and evidence checking stay in the worker. Selector changes read
prepared presentation data. A bounded memory cache and compatible recorded patch
measurements avoid repeated geometry work; actual preparation still checks fresh
identities. First evaluation of legacy results or new patches may take longer.

Preparation, Run, review, cross-checks and joint confirmation remain separate.
This change neither starts scientific fits nor grants anatomical approval.
Software tests and saved-result replay demonstrate correct decision inputs, not
guaranteed improvement of a future owner-run fit.
