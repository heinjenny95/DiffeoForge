# Continue from the explicitly selected pilot fit

The saved-fit comparison and method card both let a researcher choose a starting
field without approving its anatomy. Previously an empty problem-mark list was
treated as a reason to inspect the template. Selecting the method card could
also leave the comparison recommendation active. The selection was stored, but
the primary action did not advance from that selection.

dev219 normalizes both explicit selection paths in journal order and binds the
next action to the chosen inspected field. When an existing verified default
experiment is available, the pilot offers that experiment directly. Remaining
marked problems use the existing eligible protected correction. If no compatible
experiment is available, the next view names the chosen field and asks for the
missing correction instructions rather than repeating the fit comparison.

The selected source's feedback and quality flags drive its recommendation. A
rejected alternative's alignment hypothesis does not become a diagnosis of the
selected reconstruction. Explicit alignment or topology concerns on the selected
source still open the saved input overlay with their reason. That overlay is a
diagnostic comparison of unmodified template and original; it performs no
alignment, optimization or anatomical approval.

Green instructions retain their inspected source. If a later method-card choice
conflicts with that source, the researcher must inspect and confirm the green
areas on the chosen field before a correction can be prepared. A new protected
repair of a provisional field remains separate from unchanged numerical
continuation. Failed native guards cannot manufacture continuation eligibility.

Only the active source's adjustment panel is presented alongside its primary
action. The other method can still be explicitly selected on its card.

Controller and Qt regression journeys cover both selection buttons, empty marks,
stale alternative feedback, genuine selected-source input concerns, subsequent
local marks, green-source confirmation and failed-check provisional repairs.
Preparation preserves the exact selected field and requires a separate Run.
A mutation-denying replay of the reported saved state confirms that guidance can
be read without rewriting inputs, reviews or native evidence. Numerical settings,
existing contracts and anatomical decisions are unchanged by this UI repair.
