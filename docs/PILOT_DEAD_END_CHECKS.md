# Pilot dead-end workflow checks (dev174)

The owner requested checks of whole navigation paths before receiving another
pilot update. Qualification covers 119 distinct source workflow/UI cases,
including 38 additional dead-end cases, plus exact-product interface checks and
a read-only replay of an existing approved pilot state. Controller results in
these workflow tests are synthetic; they are not new anatomical fit evidence.

| Path | Checked outcome |
| --- | --- |
| Suitable composed regional fit | Current result remains reviewable; explicit next-animal action prepares one separate check without transferring another animal's field or approval. |
| Repeated click / reopen | Twenty clicks dispatch one preparation; closing and reopening the new plan retains the same animal and leaves Run available without starting it. |
| Unreviewed or rejected result | Review stays available; rejected results expose the saved starting-fit work route, while approval cannot be bypassed. |
| Method preference / failed or exhausted search | Preference is distinct from approval; another declared hypothesis and saved fields remain reachable without repeating an identical rejected calculation. |
| Individual reviews / common model / joint | Individual shape records do not count as common-model coverage. The complete synthetic sequence reaches separately reviewed common checks, joint review, time resolution, final completion and return to atlas setup. |
| Joint regression | A retained accepted individual field can be selected explicitly; the rejected joint field cannot silently become that single-form seed. |
| Interrupted or numerical-guard stop | Retry permissions remain bound to the actual stop evidence; unknown or changed scientific input is explained rather than approved automatically. |
| Finalization failure | Injected schema, HTML and completion-event failures can be retried using saved evidence, with no new fit, duplicated final decision or lost review. |
| Converged / capped final result | Integration, anatomical approval and convergence remain separate. An eligible capped result requires explicit provisional finish; repeated finish is idempotent and the completed dialog returns to atlas setup. |

Exact-product checks cover light/dark and larger-font progress actions,
settled-preview review, intermediate-review and export states, saved-fit
recovery and direct cancellation of a harmless isolated process session. That
cancel check took 17.672 seconds, preserved its test checkpoint and left an
outside test process alive. It started no optimizer.

The existing owner state was read without preparing a trial, fitting again or
changing its approval. Source identity and numerical protocol were verified; the
full presentation was also prepared using isolated read-only distance helpers.
The next-form action targets a different animal while retaining the suitable
individual result. An incompatible source remains a deliberate input-review
stop, with result inspection available. One common model may still fail to
reproduce an independently refined local fit; its quality needs separate review.
