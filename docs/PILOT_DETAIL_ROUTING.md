# Retained detail correction after symptom rewording

A reviewed long regional fit can pass its field and preservation checks while
still leaving projections too short for the owner's purpose. Rewording the
remaining symptom between **detail** and **missing** previously suppressed the
trusted-field evidence used to recommend finer local movement. The workflow
could therefore offer another broad-basis method comparison instead.

The local-resolution selector can now obtain the same verified prior-field
evidence for this specific symptom pair. It proposes a **new residual-field
hypothesis**, retaining the improved broad field and using the existing measured
capture and movement-scale policy. It does not transfer the reworded request to
an unchanged-objective numerical continuation: that route retains its strict
symptom check.

All existing mark/source bindings, reviewed-feedback requirements, substantial
iteration allowance, finite accepted state, per-region measurements, preservation,
intersection and spatial/temporal checks remain necessary. Changed marks,
untrusted fields and failed quality cannot select this route. Other symptoms
retain their existing behavior. There is no native solver, objective, cap,
tolerance, precision or integration-grid change.

## Verification and limits

Both directions of symptom rewording reproduced the old broad-method route in
regression tests before the repair. The updated selector chooses the finer
residual route; unchanged-objective continuation remains unavailable for the
reworded request. Negative checks cover changed marks, absent field trust and
failed preservation. Existing continuation, capture, numerical-grid and iteration
policy checks retain their gates. A stale synthetic search fixture with no plan
also failed on unchanged prior source; its fixture now supplies the required plan.

A read-only replay on completed saved evidence independently verified the
accepted field and reproduced the before/after proposal change. It started no
optimizer, prepared no successor and left the original evidence unchanged.

This repairs trial selection, not mathematical fitting throughput. A denser new
field can cost more per step; fewer unhelpful broad comparisons and anatomical
success still need practical confirmation. Numerical improvement is not proof
that a missing projection has become adequate. No runtime speedup percentage or
finished-fit guarantee is established. Existing prepared or running trials are
unchanged. The owner subsequently authorized a tested dev164 installation.
