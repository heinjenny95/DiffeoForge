New, explicitly marked full-target varifold singleton probes can use the existing
Deformetrica 4.3 L-BFGS optimizer with the unchanged finite accepted-state observer.
This is separate from regional attachment. It does not change the native
likelihood, gradient, line search, integration equations or installed runtime.

The declaration requires one original target, one full surface object, explicit
original controls, frozen template and controls, Float32, a singleton calibration
plan and fresh optimizer history. Regional objectives, coordinate conditioning,
surface-gather adapters, timed review, joint/PCA execution and automatic recovery
cannot be inherited into this scope. Unsupported combinations fail before dispatch.

The preparation plan and run manifest protect the scope, engine policy and every
generated asset. Native startup verifies input/XML/runtime/code identities before
the first objective evaluation. Accepted finite evaluations, callbacks and native
exports remain bound. The completed-field reader uses the original protected
control-point bits and the matching finite accepted momentum export. It does not
replace the native exported files or reinterpret unmarked historical fields.

Qualification covers cold and staged initialization on CPU/Torch and CUDA/KeOps.
The 86 focused configuration, preparation, original-basis, backend and guided
initialization checks include unchanged historical regional contracts.
All four paired public native controls have exactly identical objective/gradient
traces, accepted callbacks and exported momenta with and without the observer.
A changed protected target is rejected before native evaluation. A separate
ordinary product preparation/worker/report journey passes all lifecycle and
inventory checks and loads the exact original basis. A dedicated public native
cancellation case returns a verified stopped state in about 2.2 seconds after
the request; this is an observed test result, not a universal latency guarantee.

This infrastructure does not itself expose a new pilot suggestion or establish
fit quality, convergence, anatomy or a shared-cohort model. Those finite workflow,
surface/time-resolution and human-review gates remain separate. Existing regional
assets and prepared/running contracts retain their exact earlier bytes and scope.
