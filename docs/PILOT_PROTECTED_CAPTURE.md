# Protected missing-feature capture

A far missing projection can need a broad attachment range and a much smaller
movement kernel at the same time. Those scales now have separate roles in new
protected detail requests. This policy does not alter existing fields or
same-objective numerical extensions.

The policy applies to explicit missing/detail requests with an inspected Retain
area, no rigid-shape guides, and a per-brush forward mismatch larger than that
brush's radius. Subsequent detail requests in that protocol remain eligible.
Ordinary smaller misses and other symptoms retain their existing route.

The next trial works on the brush with the largest measured symmetric tail. All
original instructions remain bound to its evidence and visible in the review.
The proposal names the active area and requires reviewing the other projections;
a partial-area trial cannot manufacture whole-shape anatomical approval.

Capture width is twice the measured symmetric 95th-percentile distance between
the actual free source patch and the original target patch. Two deterministic
2,048-point samples in each direction estimate this geometric range, without
inventing anatomical point pairs. Selection uses the current numerical output;
native source objects still use the corresponding incoming material coordinates.

The movement width is halved from the selected seed only until it is at most
half the active brush's radius (half maximum half-span for boxes). It is not
bounded below by twice the capture width. Controls cover both the source and
target at that movement scale, including actual free material. Unsupported
learned controls receive a separate zero residual with the full prior field
preserved; nonzero momenta are never moved onto another basis.

The complete useful numerical starting field supplies automatic outside
protection. Explicit Retain keeps its independently inspected reference. Its
native noise is at most the unchanged displacement bound divided by 16; the
post-fit bound remains diagonal times 1e-4. New trials in this policy use at
least 145 native RK2 points. Native L-BFGS, Float precision, finite/line-search
guards, iteration headroom and the ten-active-minute review remain unchanged.
Temporal/spatial refinement, intersections and all preservation gates still run
on the composed field before numerical qualification.

Engineering cases cover independent scales, per-area scheduling, progress reuse,
unchanged continuation routes, unknown reverse samples, active-scope binding,
measured patch capture, stronger native weighting with the same acceptance bound,
and native time-grid preparation. These are explicit numerical hypotheses, not a
universal anatomical fit or ten-minute completion guarantee. Each new specimen
and any later shared-cohort protocol require their own verification and review.
