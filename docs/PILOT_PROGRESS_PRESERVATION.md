# Preserve numerical progress independently of explicit Retain

When a new field improves one projection and the next trial addresses a different
area, its automatic outside anchors must not pull the improved projection back
toward the older Retain comparison. The former preparation used one geometry for
both roles, even when the numerical seed and explicit Retain source differed.

New regional preparation binds two references on matching material connectivity.
The explicit dense fixed patch keeps the inspected Retain field. Automatic
outside anchors use the current numerical seed, filtered by the existing
already-close surface criterion. Fixed vertices are excluded from the separate
automatic anchor object, avoiding contradictory targets for those same vertices.
Focus-source selection uses current numerical geometry while excluding every
fixed-incident triangle. No independent fields are spliced together.

The automatic reference mesh is an immutable staged asset. Its saved source run
and manifest are recorded separately. Full-field QC evaluates that numerical
reference on the same refined original-source grid and time resolution as the
candidate, while explicit Retain is still checked against its own field. If the
two source runs coincide, the same verified evaluation is reused. New automatic
anchors are not anatomical approval or hard constraints. Existing bounds and
already-close confidence thresholds remain unchanged.

Verification: 85 targeted objective/search, continuation, numerical-policy and
Retain-reference cases pass, including two new cases. A public three-part fixture
holds a newly improved second part during correction of the first, while its
explicit fixed third part retains the older inspected reference even when that
part differs in the numerical seed. Losing the new second part fails outside
preservation; tampering with its staged reference fails identity checks. Lint
passes. Native difficult-specimen experiments remain separate.

Legacy plans without this reference retain their existing interpretation. No
saved plan, field, journal or owner run is rewritten. Installed runtime remains
dev175 until a separately verified successor is delivered.
