# v123 — offline presentation mode

Open **DiffeoForge Demo** from the Windows Start menu, choose **Open demo** on the
normal setup page, or launch `diffeoforge-desktop --demo`. Eight stations can be
opened immediately in any order, with no project setup or analysis prerequisites.

The dedicated window provides mesh rotation/zoom, subject switching, surface
landmark picking, stored alignment comparisons, illustrative pilot controls,
recorded convergence playback, original/reconstruction toggles, temporary review
labels, selectable PCA axes/scores, illustrative endpoint blending, metadata
groups and report/export previews. **Reset demo** restores the presentation;
closing discards its session. There is no connection to a local/server optimizer.

The small public fixture combines CC0 synthetic surfaces and genuine saved
Deformetrica 4.3.0 CPU reference endpoints, residuals and convergence. Cartesian
momenta PCA and similarity alignment were prepared offline. The persistent demo
banner and station explanations distinguish recordings from illustrations. The
blend slider does not claim native Shooting or PC deformation; pilot cards do not
claim a newly fitted candidate; group labels do not support biological inference.
Validation, publication export and checkpoint/resume operations are explained or
previewed, never executed. Full native flow trajectories are not in this fixture.

The demo imports no production window/controller, run service or PCA calculator.
It does not load recent projects, save settings, write QC evidence, unlock real
workflow gates, run a backend or contact a server. Reuse is restricted to display
canvases and the read-only optimizer plot. The normal workflow and fit criteria
remain unchanged. Package resources include the bounded fixture, hash and
licenses; PyInstaller explicitly includes them.

Regression coverage checks public-source hashes/PCA, finite mesh geometry,
navigation without prerequisites, actual surface picking, replay/seek/pause,
review/morph/reset isolation, camera controls, report previews, launcher startup
from another directory and unchanged normal workflow gates. A fresh-interpreter
probe forbids process starts, settings writes and persistent writes, and checks
that production/analysis services are never imported. Visual and frozen/installed
qualification remain separate delivery checks.
