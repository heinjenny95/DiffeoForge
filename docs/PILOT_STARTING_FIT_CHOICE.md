# Choose a saved starting fit when Better conflicts with quality checks

A visually useful correction can receive Better feedback while still failing a
surface-preservation, spatial-resolution, time-grid or intersection check.
Previously the preference selector then silently returned its older comparison.
The next Improve trial could therefore start from a different saved field than
the researcher expected.

## Explicit decision

dev223 leaves the working source unselected for this conflict. The pilot names
the latest and earlier fits with method and trial labels, lists the recorded
quality reasons and presents one primary **Choose starting fit…** action. Neither
alternative is an automatic winner. Inspection opens the existing saved-fit
viewer; opening or cancelling the chooser writes no preference and starts no
computation. The selected original and reconstruction must settle before the
researcher can save that exact source and its correction instructions.

Better alone still grants no anatomical approval or numerical eligibility.
Selecting a provisional field is a decision to work on that field, not a waiver
of its checks. Native finite-state guards, unchanged-continuation qualification,
geometry checks and later atlas review keep their existing requirements.

## Preserve the areas that already fit

Deleting a red instruction removes that instruction. It does not add a green
Keep unchanged constraint. When an inspected local review narrows a previously
larger set of problem areas, the saved-fit viewer can propose the removed areas
as green instructions. These are editable drafts: only explicit Save records
them. Cancel retains the old instructions.

The assistant does not automatically resize overlapping areas. If a removed area
overlaps another instruction, it explains that no green conversion was made and
asks the researcher to mark smaller green areas where appropriate. The existing
source bindings and green-reference conflict checks remain in force.

## Preparation and compatibility

Cached guidance does not authorize a source. Fresh preparation rechecks the
feedback journal and refuses a new adjustment until the explicit choice is saved.
Direct transition and working-fit preparation paths enforce the same gate.
An expected decision binding is carried through background inspection and final
Save; a later conflicting decision makes that older dialog stale.

Existing prepared and running numerical contracts are not rewritten. Historical
journals, saved reconstructions, marks and approval records remain unchanged.
The revised behavior applies when reading the conflict and preparing subsequent
work. No tolerance, iteration allowance or fitting equation is changed.

## Verification boundary

Focused checks cover warning reasons, absence of an automatic seed, explicit
latest and older choices, stale and forged bindings, inert cancellation,
feedback-only inspection, narrower correction drafts, overlapping instructions,
and preparation from the selected source without optimizer dispatch. Existing
feedback, working-fit and pilot journeys remain regression coverage. Private
mutation-denying replay checks the reported saved case without fitting, replaying
a field or changing owner evidence. Package verification and scientific fit
validation remain separate from these engineering checks.
