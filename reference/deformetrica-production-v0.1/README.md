# Deformetrica production engineering qualification v0.1

This directory records the compact, privacy-safe summary of the 11 August 2026
combined 300-subject, 10,000-face CUDA qualification. The underlying Coxa meshes
and approximately 2.2 GB of immutable run artifacts remain local and are not
published. `qualification-summary.json` records their complete-file hashes and the
explicit replicated/nonbiological boundary.

The observation supports DiffeoForge software-scale, storage, cancellation, and
checkpoint-resume claims on the measured Windows/WSL/RTX 4080 machine. It does not
support biological parameter, registration-quality, convergence, or PCA claims.
